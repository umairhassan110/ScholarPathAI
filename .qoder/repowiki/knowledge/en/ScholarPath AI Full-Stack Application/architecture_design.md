Two independently deployable services communicate over HTTP: the React frontend (Vite + Tailwind) calls REST endpoints under `/api/*` exposed by the Express backend. The backend is a single-file application (`index.js`) that wires all routes — auth (`/api/auth/*`), profiles, scholarships, universities, matches, shortlist, applications, attestation steps, language prep guides, document tools, chat placeholder, and notifications — behind a shared `authenticateToken` JWT middleware that validates `Authorization: Bearer <token>` against `JWT_SECRET`. All persistent state lives in Supabase (tables: `profiles`, `scholarships`, `universities`, `matches`, `shortlist`, `applications`, `attestation_steps`, `notifications`, plus storage bucket `cvs`); the frontend consumes these APIs to render its landing page and tabbed dashboard. Cross-cutting concerns (CORS, JSON parsing, file upload via multer, environment validation at startup) are applied globally before route registration.
