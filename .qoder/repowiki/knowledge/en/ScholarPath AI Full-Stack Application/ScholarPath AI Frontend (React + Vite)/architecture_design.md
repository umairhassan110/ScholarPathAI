Single-page app built with Vite + React 19 and react-router-dom v7. `src/main.jsx` mounts the root into `#root`, wrapping `<App />` in StrictMode. `src/App.jsx` defines two top-level routes: `/` → Landing page and `/dashboard` → Dashboard. The Dashboard is a stateful shell that owns shared profile/document state and renders one of seven tab panels (`OverviewTab`, `ProfileTab`, `AttestationTab`, `UniversitiesTab`, `ScholarshipsTab`, `BuildCvTab`, `FaqTab`) via a local `tabContent` map driven by a `TABS` config array. Shared UI primitives (`Card`, `Button`, `Badge`, `SocialIcon`) live in `src/components/UI.jsx`; cross-cutting widgets (`AuthModal`, `ChatWidget`) are imported from `src/components/`. All domain data — student profile, required documents, university matches, scholarships, attestation steps, FAQs — is centralized in `src/data/mockData.js`, which pages import directly so swapping static data for an API later requires changing only this file. Styling uses Tailwind CSS with custom design tokens defined under the `sp-*` namespace (e.g. `bg-sp-bg`, `text-sp-navy`, `border-sp-border`) configured in `tailwind.config.js` and consumed globally via `index.css`.
